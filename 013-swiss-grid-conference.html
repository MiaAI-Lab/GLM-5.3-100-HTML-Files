01 — Premise

Structure is not a constraint on form; it is the material form is made from. Three days on modules, measure, and the moral weight of the flush-left margin.

02 — Method

Twelve columns. One baseline. No ornament survives the edit. Every element on this poster sits on the same arithmetic — press G to see the scaffolding.
318 seats in the main hall. Set in Helvetica or nearest system kin. Typeset without a single image — type is the imagery.

03 — Manifesto A column is a contract: what begins aligned shall return aligned. Whitespace is not empty; it is load-bearing. We hold these truths at 8pt increments.
