# Hall of One Hundred

A gallery of **100 self-contained HTML pages** generated by **GLM-5.3**.
Each piece is a single offline file (HTML + CSS + JS, no build step) plus a sidecar `.txt` that records the prompt and notes.

Live gallery: **https://miaai-lab.github.io/GLM-5.3-100-HTML-Files/**

Open [`index.html`](index.html) locally, or browse the same file on GitHub Pages.

## How to view

```bash
# from this directory
python3 -m http.server 8080
# then visit http://localhost:8080/
```

Or open any `NNN-*.html` file directly.

## Layout

| File | Role |
| --- | --- |
| `index.html` | Gallery index linking to all 100 pieces |
| `NNN-slug.html` | Standalone piece |
| `NNN-slug.txt` | Prompt (and generation notes) for that piece |
